## Test Structure

**Suite Organization:**
```python
def test_scenario_2_damage_vs_value():
    """
    Verifies that in Scenario 2, the most damaged road (R10, damage_factor 2.5, effort 9.8)
    is NOT the highest-ranked intervention.
    """
    nodes = get_synthetic_city_nodes()
    roads = get_synthetic_city_roads("Scenario 2: Critical Corridor Disruption")
    ce = CascadeEngine(nodes, roads)
    ie = InterventionEngine(ce)

    ranking_df = ie.evaluate_all_interventions()
    top_cand = ranking_df.iloc[0]
    
    # Verify R10 is NOT top
    assert "R10" not in top_cand["candidate_id"], "R10 (most damaged) should not be the top intervention!"
    
    # Check baseline comparison
    comp_df = ie.evaluate_baseline_heuristics_comparison()
    assert not comp_df.empty
    print(f"[PASS] Test Scenario 2: Most Damaged Road (R10) != Most Valuable ({top_cand['intervention']}).")
```

**Patterns:**
- **Setup:** Instantiates fresh `CascadeEngine` and `InterventionEngine` instances per test function using deterministic scenario constructors (`get_synthetic_city_nodes()`, `get_synthetic_city_roads(scenario_name)`).
- **Execution:** Calls public evaluation methods: `ie.evaluate_all_interventions()`, `ie.get_dynamic_recommendation()`.
- **Assertion:** Directly validates expected state, population sums, ranking outcomes, and immutability invariants.
- **Reporting:** Prints `[PASS] <Test Description>` upon completion of each test function.

## Mocking

**Framework:**
- None. The synthetic prototype relies on deterministic in-memory fixtures and does not require mock frameworks (`unittest.mock`).

**What is Tested Directly (Real Execution):**
- Full graph generation and NetworkX pathfinding.
- Accessibility calculations across all 11 nodes.
- Utility formula calculation and Pandas dataframe sorting.
- Dynamic natural-language explanation formatting.

**What is NOT Mocked or Tested:**
- Streamlit UI rendering (`cascadebreak-mini/app.py` is untested).
- Folium map generation (`cascadebreak-mini/visualization.py` is untested).
- Machine learning prediction interfaces (`cascadebreak-mini/ml_prediction_interface.py`).

## Test Types

**Data Integrity Tests:**
- Validates synthetic data invariants, such as ensuring total population sums exactly to 59,000 across all population clusters (`test_data_integrity`).

**Scenario Logic & Algorithmic Tests:**
- Validates the core thesis: "Most Damaged Road != Most Valuable Intervention" (`test_scenario_2_damage_vs_value`).
- Validates complex multi-route bottlenecks requiring temporary pontoons or combined packages (`test_scenario_3_multi_route_bottleneck`).

**Edge Case & Fallback Tests:**
- Validates zero-disruption scenario behavior (`test_scenario_4_zero_disruption_fallback`) ensuring system outputs `NO BENEFICIAL INTERVENTION IDENTIFIED` rather than hallucinating an intervention.

**State Invariance & Immutability Tests:**
- Validates that running counterfactual simulations does not alter edge counts or properties of the baseline flooded graph (`test_non_destructive_simulation`).
